# 📚 XAUUSD ICT Master Summary

A single-file study reference synthesizing Smart Money Technique (SMT) and ICT (Inner Circle Trader) concepts into one structured document, applied specifically to XAUUSD trading.

## Problem

SMT/ICT concepts are scattered across many separate sources (videos, PDFs, forum threads) with inconsistent terminology. This document consolidates the concepts I actually use into one reference, organized top-down by timeframe.

## Contents

- **Regular SMT & Divergence SMT** — concept definitions and the key distinction between them (divergence gives directional bias only; entries still require lower-timeframe confirmation)
- **SSMT & CIC variants** — extended SMT concepts
- **Top-down multi-timeframe framework** — 1D → 6H → 90M → M15/M1 analysis flow applied to XAUUSD
- **Correlated asset context** — using XAGUSD (silver) and DXY (dollar index) as confirmation/divergence references for XAUUSD setups

## Tech Stack

- Vanilla HTML/CSS — formatted as a static single-file reference document

## Why I built it this way

Synthesized from source material (SMT/ICT PDFs) into a single-page reference so the framework is fast to review before a trading session, rather than re-reading scattered original sources each time.
